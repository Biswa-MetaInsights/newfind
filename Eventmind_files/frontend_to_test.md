## 3. Decisions taken and still open
- **Zone label on the event page**: beside the time, on the right of the date row. It is a real abbreviation that follows the date: CET in winter and CEST in summer for Brussels/Europe, EST/EDT, PST/PDT, IST, AEDT/AEST, SAST and so on elsewhere (Gautham, 2026-11-17). Zones with no common English abbreviation (e.g. Tokyo) show the offset form, "GMT+9".
- **Year on the event page**: kept. Only event **cards** lose the year, to make room for the venue name (Gautham, 2026-11-17).
- **Hero "Tonight" quick pick**: removed. No "Today" chip was added to the hero; Explore already has a Today date preset (still returns nothing until the backend date bug is fixed).
- **"Suggested for you"** becomes a filter tab after "All" (signed-in users with results), replacing the separate carousel; Old page's always-empty "Recommended" tab branches are removed. Done in Phase 2: the tab counts only in-person and hybrid suggestions, because the row is "Happening in {city}"; an online-only suggestion does not show there. Say if online ones should count too. **Updated 2026-11-17 (Gautham):** online suggestions count too: the Online Events row gets its own "Suggested for you" chip after "All" (online and hybrid suggestions); the city row keeps in-person and hybrid. If the chip never shows, check whether `/event/recommendations` drops online events when lat/lng are sent (same family as `backend_to-do.md` §1).
- **Explore's location picker is outlined** (Gautham, 2026-11-17): `CityPicker` has an `outlined` prop (2px `--brand-control-border`, page background), passed only by Explore's top bar. The picker has no hover change at all (Gautham, 2026-11-17, replacing his earlier "text turns green").
- **FeatureBand**: deferred, see Reminder 1 (Gautham: current version is fine for now).
- **City tooltip** ("Click here to change your location"): laptop/desktop only, i.e. `lg+` with a hovering pointer; phones and tablets never see it. Still only on the navbar's trigger (Gautham, 2026-11-17).
- **Home city-row radius (200 km)** is a question, in `backend_to-do.md` §9.
